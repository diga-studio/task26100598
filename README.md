# task26100598

`itemcf`：由上层调用的 Go ItemCF 推荐库，评分快照与计算结果全部保存在进程内存中。

## 用法

```go
rec, err := itemcf.Build(ratings, refDay) // ratings: []itemcf.Rating，refDay 为参考日 T
if err != nil { /* 非法评分/日期/重复记录 */ }
recs := rec.Recommend(userID, blacklist)  // 最多 20 条，含得分与贡献解释
```

- `Rating{UserID, ItemID, Score, Day}`：Score 取 1–5，Day 须在 `[T-365, T]` 内，(用户, 商品) 组合不重复。
- 权重 = (评分 − 用户均分) × 2^(-(T-评分日)/30)；商品相似度为全用户坐标上的权重余弦。
- 候选 = 快照全部商品 − 用户已评 − 黑名单；得分按历史权重×相似度求和，再除以历史权重绝对值之和与 ln(2+评分人数)。
- 按得分降序、商品 ID 升序返回前 20；每条结果附绝对贡献最大的 3 个历史商品及其余贡献之和，两部分相加精确还原得分。

## 测试

```sh
go test .          # 含规模测试（约 15s）
go test -short .   # 跳过规模测试
```

规模测试：10 万用户、10 万商品、200 万评分，含 10 名各 2 万条评分的重用户与 1 件 5 万人评分的商品；
构建 + 100 个用户完整推荐（含解释）实测约 8s（上限 60s），峰值内存约 282MiB（上限 512MiB），
并对抽取用户用独立实现核对完整候选排名。
